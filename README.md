# vscode-cleaner-contextmenu

`vscode-cleaner-contextmenu` is a plugin that can be used with the ["Custom CSS and JS Loader" VSCode extension](https://marketplace.visualstudio.com/items?itemName=be5invis.vscode-custom-css) that cleans up the VSCode context menu

## Installation:

1. Install the ["Custom CSS and JS Loader" VSCode extension](https://marketplace.visualstudio.com/items?itemName=be5invis.vscode-custom-css).

2. Add to `settings.json`.

```json
"vscode_custom_css.imports": ["https://raw.githubusercontent.com/antoniszymanski/vscode-cleaner-contextmenu/refs/heads/dist/main.js"]
```

3. Activate command "Reload Custom CSS and JS".

4. Restart.
